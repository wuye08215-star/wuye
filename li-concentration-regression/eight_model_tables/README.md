# 8种模型：改进方法、运行结果和图册

先打开 **All_8_models.xlsx**：包含9个工作表，第一张为总对比，其余8张为RF、SVR、LightGBM、MLP、XGBoost、高斯过程、样条加性回归、RF＋高斯过程组合。

也提供9份独立Excel：00_Comparison.xlsx及01_RF.xlsx至08_RF_GP.xlsx。放在同一文件夹后，独立总表的模型链接可跳转对应文件。

每张模型表先展示结论与前后结果，再通过顶部导航查看：改进过程、参数解释、图册、候选验证记录、273条预测及来源。所有图已嵌入，离线可查看。原宽树图可放大或另存。默认只打印开头概览，图册和明细在下面；需要打印它们时选择对应区域。

这8个是建模方案，其中RF＋GP是组合，并非8种独立基础算法。新增4个方案没有同名原版，不虚构“改前”分数。RF用最新4因子结果0.5538；LightGBM后续试验0.4851下降，因此明确建议保留原版0.5396；MLP训练后仅0.3733，到0.5007的大部分增益来自一条负预测修正。

所有主要指标使用同一273条测试记录，目标ln(1+Li)。训练CV只用于选型；固定测试已被多轮查看，结果不能代替独立外部验证。R²不是准确率，变量重要性不是因果贡献。原图末位和同环境复现可能略有差异，表格注明来源。

本轮只汇总已保存的运行记录和图像，没有新增训练或挑换测试集。source_manifest.json保存源文件哈希及表内导航位置，供核查。

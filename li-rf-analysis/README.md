## 主要结果

以下使用全部1365条记录。随机留出：回归80/20，分类70/30；空间验证为1°网格分组五折，表中为空间折外预测汇总。

| 指标 | 参考模型 | 修订模型 |
|---|---:|---:|
| 回归随机测试集 R²（ln(1+Li)尺度） | 0.4233 | 0.4257 |
| 回归空间分组 R²（同上尺度） | 0.1253 | 0.1835 |
| 分类随机测试集准确率 | 74.88% | 73.41% |
| 分类随机测试集 ROC-AUC | 0.8291 | 0.8320 |
| 分类空间分组准确率 | 72.31% | 66.59% |

参考分类器是新建立的分类基准，不能与原回归 R² 直接比较。修订模型暂用5个气候字段：18个土壤字段存在完全重复/固定倍数关系，其真实属性待核实。分类标签按原始Li>30重新生成，纠正现有1/0列中的36条阈值不一致记录。

回归改善有限，分类准确率没有提高；修订主要完善了标签、训练内调参、空间验证和误差报告。变量重要性不代表因果效应。请先核实HWSD属性提取，再重新训练并评价。

# Li 随机森林代码与论文核对说明

结论：当前脚本做的是连续浓度回归；论文做的是高/低 Li 分类。两者目标与评分不同。现有数据还存在必须核实的土壤字段异常，单靠调参无法解决。

## 1. 从论文确认的任务背景

引用为论文印刷页码，PDF 文件页码约为印刷页码加 8：

- 第 7–12 页：地下水 Li，单位 μg/L；清洗后 1365 条记录，范围 0–4310 μg/L。第 12 页明确以 `Li > 30` 为高 Li，输出高 Li 概率，目标是全国空间预测。
- 第 11 页表 2.3：5 个气候变量来自 CGIAR / WorldClim；18 个土壤变量来自 HWSD / HWSD v1.2；另有地质变量 US。
- 第 12 页：高 Li 719 条、低 Li 646 条。这与上传 Excel 中 `(Li > 30)` 的计数完全一致。
- 第 12–13 页：方法写 70/30 划分、训练内十折交叉验证、分类准确率/精确率/召回率评价。第 14 页将最终概率推广到全国 1 km 栅格。

`RandomForestRegressor` 回答“预测浓度是多少”；论文需要的 `RandomForestClassifier` 回答“超过 30 μg/L 的概率是多少”。R²=0.539 不是准确率 53.9%，不能与论文约 0.78 的分类准确率比较。分类是另一项任务，换任务后分数升高不等于浓度预测改善。

## 2. 数据中已核实的问题

1. 两个 QSH.xlsx 完全相同，均为 1365 行、29 列，不是两个独立数据集。
2. 下列 15 列逐行完全相同：CECS、CECT、SpH、SOC、SCF、SSiF、SSaF、SGC、TCF、TSiF、TSaF、TGC、TpH、TOC、ST。另有 OAR=2×CECS、SNRC=2×CECS、SNA=3×CECS。18 列只包含一个独立数值方向。土壤属性的含义各异，不能据此解释真实土壤作用。论文说明了数据来源，但没有解释这些数值为何相同。
3. “可能误用了 HWSD 制图单元编号或错误属性字段”是待核实的推测，尚未证实。应核对栅格值、HWSD 属性连接键、字段映射、单位与比例因子；仅凭论文与现表不能恢复真实土壤值。若栅格存的是制图单元编号，需要通过正确连接键查询对应属性，并核对同一单元多个土壤组分的处理，不能直接把编号当作 pH 或有机碳。
4. 上传的 `1/0` 列恰好等于 `(Li >= 33.2)`，不是论文的 `(Li > 30)`。36 条 Li=30.1–33.1 μg/L 的观测被现成标签标成了 0。若做分类，必须从原始 Li 重建标签；该列绝不能作为输入。原回归代码已经排除了该列，并无这一项输入泄漏。
5. 论文列出 24 个候选因子，但 Excel 只有 23 个，缺少 US。不能凭空补出地质变量。
6. 当前有 15 条额外的重复坐标记录；论文说同 1 km 网格样点聚合，是否已按该流程处理仍需核实。不能不看井深/采样时间就直接删除重复位置。
7. 论文中的数量和方法口径也需核对：方法写 70/30，RF 混淆矩阵总数却为 273，等于 1365 的 20%；第 17–18 页 XGBoost 混淆矩阵正确数为 89+112=201，对应 201/273=73.63%，与摘要约 0.78 不是同一结果。可能来自不同运行/划分，需原始记录解释，不能认定已经复现论文分数。

## 3. 对原回归代码的实测

为与原图公平比较，这一节沿用原脚本的 Li≤2000 筛选，剩 1363 条。所有 R² 均为 ln(1+Li) 尺度。

| 评价方式 | 原始 RF | 暂不使用异常土壤字段、训练内调参的 RF |
|---|---:|---:|
| 原固定 80/20 测试集，273 条 | 0.5390 | 0.5450 |
| 相同坐标不跨折，五折外层/四折内层，汇总折外预测 | 0.4282 | 0.4541 |
| 1°网格不跨折，五折外层/四折内层，汇总折外预测 | 0.2302 | 0.2252 |

固定测试集原 RMSE=0.7411，改后=0.7362；加入经纬度的探索对比 R²=0.5516，也没有大幅改善。不能据此声称稳定显著提升。原图上传的 R²=0.538933 与本环境复现值 0.538987 很接近；环境 scikit-learn 版本为 1.8.0。

空间五折的逐折 R² 与汇总 R² 是不同统计量：改进模型逐折 R² 平均约 0.0133、折间标准差约 0.3335，汇总 R² 为 0.2252。多个网格折中的预测仍较差，不能只挑最好的一折报告。网格大小是诊断设置，不是经过证明的最优尺度；边界两侧仍可能空间接近，这不等价于独立跨省外部验证。

原始浓度尺度也明显更难：原固定测试集反变换后的 R²≈0.2266，修改后≈0.2370。log 模型经 `expm1` 得到的值，不保证是原始浓度的无偏条件均值。

## 4. 回归修改版做了什么

- 保留 Random Forest，不引入新的学习库。当前暂用五个气候字段，土壤数据修复后再明确加入；不把异常编号当作土壤作用的解释依据。
- 在训练集内部随机搜索树深、叶子样本数、特征抽样和样本抽样；400 棵树用于控制重复拟合成本。原参考模型仍使用 1000 棵树。
- 同坐标/同空间网格在相应内层验证中不跨折；空间外层每折重新调参，不使用外层测试答案选参数。
- 默认保留全部 1365 条非负 Li 观测，不按效果删除高浓度记录。`--li-max 2000` 仅用于复核原脚本口径，科学上是否排除需独立依据。
- 同时输出 ln(1+Li) 和原浓度尺度的 R²、RMSE、MAE；NSE 在此定义下与 R² 相同，不重复当成独立指标。
- 输出预测值、原 Excel 行号、每折参数、训练 CV 记录和测试集置换重要性标准差，便于复查；使用 Agg 绘图，不依赖 Tk 桌面。

变量之间高度相关：AET 与 AI 的 Pearson r 约 0.981，AET 与 Alpha 约 0.988。单变量置换重要性受这种相关结构影响，既不是因果效应，也不是可相加的“贡献百分比”；置换标准差也不是置信区间。在土壤数据未修复前，不能从重要性低推出“土壤不重要”，也不宜直接宣称气候是已经证实的主控机制。

论文描述 log10(1+Li)，原代码实际为 ln(1+Li)。二者只差常数倍：换对数底数不会从原理上改善 R²，只会改变对应 RMSE/MAE 的数值尺度。树图中的 `plot_tree(max_depth=2)` 只限制显示层数，不是训练树只有两层。

## 5. 回归完整数据的结果与分类版本

默认不删高 Li 记录，用全部 1365 条数据实跑，结果如下：

| 评价 | 原参考回归模型 | 修订回归模型 |
|---|---:|---:|
| 80/20 随机测试集，ln 尺度 R² | 0.4233 | 0.4257 |
| 80/20 随机测试集，原浓度 R² | 0.2395 | 0.2559 |
| 空间分组五折汇总，ln 尺度 R² | 0.1253 | 0.1835 |
| 空间分组五折汇总，原浓度 R² | 0.0261 | 0.0456 |

完整数据与 Li≤2000 子集的随机测试样本不同，不能把两组分数的差异只归因于极值是否保留。两种数据范围都说明浓度预测仍然存在明显局限。

用户已确认保留回归和分类两种任务。分类版 `Li_RF_分类版.py` 使用全部 1365 条记录，以 `(Li>30)` 重建标签。参考分类器使用原代码对应的树数、深度、叶子大小及23列；这是新建立的分类参考，**不是把原回归 R²当成分类准确率**。修订分类器暂用5个气候字段，70/30分层划分后，在训练内做十折分层分组参数搜索；为概率判别按ROC-AUC选参，分类准确率在固定0.5截断点另行评价，没有在测试集上挑概率截断点。空间验证采用外层5折/内层4折空间分组，不能将混合空间的随机十折宣称为跨区域验证。Brier分数用于检查概率误差，不代表已经完成概率校准。



分类版已完整实跑，结果如下（同一协议中的两模型使用完全相同外层测试样本）：

| 评价方式 | 分类器 | Accuracy | ROC-AUC | 高 Li Recall | Brier（越低越好） |
|---|---|---:|---:|---:|---:|
| 70/30分层随机留出，410条 | 23列参考分类器 | 0.7488 | 0.8291 | 0.7824 | 0.1658 |
| 同上 | 5气候字段修订分类器 | 0.7341 | 0.8320 | 0.7361 | 0.1663 |
| 空间分组五折，1365条折外预测汇总 | 23列参考分类器 | 0.7231 | 0.7875 | 0.7580 | 0.1857 |
| 同上 | 5气候字段修订分类器 | 0.6659 | 0.7248 | 0.7677 | 0.2137 |

排除异常土壤列后，分类准确率没有提高；这些异常值也可能保留了位置/区域等代理信息，但它们的真实含义尚未查明。不能把“数据语义更清楚”包装成“分数更高”。目前最诚实的结论是：修订版补齐了标签、验证和误差报告，尚未解决数据质量不足造成的预测限制。土壤数据修复后才适合重新比较模型与环境因子解释。

随机留出的修订分类器训练内最优参数为：`n_estimators=400, max_depth=5, min_samples_leaf=3, max_features="sqrt", max_samples=0.75`。这个设置按训练CV的ROC-AUC选出，不保证固定0.5阈值准确率最大；不同空间外折独立选参，不能把这里的设置当作跨区域通用最优参数。

分类结果工作簿包含 metrics、fold_metrics、parameters、importance_by_fold、predictions，以及 label_mismatches（36条原标签差异）。置换重要性用AUC下降量表示，与回归的R²下降量不是同一种尺度。

## 6. 运行

建议 Python 3.12（本次实测 3.12.14）。把用户自己的 QSH.xlsx 与脚本放在同一目录：

```bash
python -m pip install -r requirements.txt
python Li_RF_回归版.py QSH.xlsx --output RF_results
python Li_RF_分类版.py QSH.xlsx --output RF_classification_results
```

复核原筛选口径：

```bash
python Li_RF_回归版.py QSH.xlsx --li-max 2000 --output RF_results_2000
```

仅当任务是位置辅助预测时，可加 `--coordinates`。加入坐标后的结果仍须通过空间验证；不宜用它把位置相关性解释为环境过程。

输出目录中的 RF分析结果.xlsx 是技术明细：metrics 为汇总指标，fold_metrics 为训练/测试逐折指标，parameters 为各折内层选择结果，importance_by_fold 为各折测试置换重要性，predictions 为带来源行号的预测。RF_validation.png 展示回归验证图。完整数据的实测结果已附在“完整数据结果”目录中，与上面沿用原筛选的对比应分开阅读。

这里没有完整全国栅格输入，未生成或验证全国分布图；概率图还需要预测栅格、坐标系、同一套属性预处理和空间外部验证。论文的描述不能替代这些实际数据。
